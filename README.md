# 興債觀測網

興櫃與可轉債市場雷達，提供興櫃公司、可轉債與上市櫃進度資訊。公開頁面讀取已驗證、原子發布的靜態 generation，不在瀏覽器直接連線市場來源。

## 本機啟動

```powershell
npm.cmd install
npm.cmd run dev
```

正式核心路由：

- `/dev-preview`：市場總覽與搜尋
- `/dev-preview/emerging`：興櫃資料，價格欄位以收盤價語意呈現
- `/dev-preview/bonds`：可轉債完整橫式資料表與明細
- `/dev-preview/ipo`：IPO 時程資料狀態

靜態市場頁入口為 `static-showcase/index.html`、`bonds.html`、`emerging.html`、`ipo-radar.html` 與 `ipo.html`。

## 可轉債公開分析工作台

工作台只整理已核准的公開盤後資料：TPEx 11406 發行條款、TPEx `cbDayQry` 可轉債盤後行情、TWSE／TPEx 標的股盤後收盤、TPEx `convSearch` 與 MOPS `t120sg01` 轉換價。已獨立核准且驗證成功時，另顯示 TPEx 三大法人日交易、贖回公告，以及上市／上櫃公司月營收。TWSA 承銷公告目前只作已核准的資料收集補充，尚未在公開工作台呈現。所有關聯均使用債券代碼或公司代碼精確比對，不以名稱模糊合併。

主要衍生欄位：

- 轉換價值 = 標的股收盤價 ÷ 當日已生效轉換價 × 100。
- 轉換溢價率 =（可轉債收盤價 ÷ 轉換價值 − 1）× 100%。只有 CB、股票與轉換價具共同有效估值日才計算。
- 剩餘單位 = 流通餘額 ÷ 每交易單位面額；剩餘比例 = 流通餘額 ÷ 發行總額 × 100%。
- 日週轉率 = 當日成交單位 ÷ 剩餘單位 × 100%；到期／賣回天數採資料日到事件日的日曆日差。

資料狀態不以猜測值補齊：`stale` 表示沿用該來源上一份完整驗證快照並保留原資料日；`archived` 表示債券已到期、贖回、餘額歸零或從官方完整名冊移除，預設列表不顯示；`accumulating` 表示歷史樣本尚不足以計算完整均線或技術指標。零成交與缺少 OHLC 保留為缺值或 gap，不製造假 K 棒。

目前沒有核准的 TTM、PS 或 TCRI 公開資料，相關條件只顯示「目前無核准公開資料／待確認」，不填零、不仿造評等。工作台是公開資料的教育性條件檢核，不構成投資建議、交易指令、部位或避險比率建議。

## 驗證

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd test
npm.cmd run build
```

缺少經驗證來源的欄位會顯示「—」或明確待確認狀態，不以推測值填補；每個資料區塊都應顯示資料日期與來源。
