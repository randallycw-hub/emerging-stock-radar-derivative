# Cycles 可轉債參考版型與官方來源核對

研究日期：2026-09-08。內部文件，不投影至前台，不構成來源核准或公開部署紀錄。

## 結論與目前缺口

可以採用參考站的密集比較表、組合篩選與發行里程碑排列。資料應直接取得官方原始資料，不擷取參考站表格充作本網站正式數據。

本次確認的是「能提供相同事實的官方來源」，不是「已得知 Cycles 私有後端怎麼抓」。未讀取私有接口、會員資料或券商資料。

查到目前發行頁空欄的具體原因：

- `static-showcase/assets/cb-workbench-v53.js` 的發行模型仍將公告、送件、生效及競拍日期設定為 `null`，尚無正式公開來源補入。增加表格欄位本身不會產生資料。
- 專案雖已取得證交所競拍資料，但 `lib/source-verification/source-ipo-events.ts` 的 `auctionMarket()` 只接受股票初上市／上櫃，正確地排除了 CB。不能用四碼股票 identity 的 IPO parser 直接吞入五至六碼 CB。
- `lib/pipeline/source-registry.ts` 的同一來源目前明定 `approvedPurpose: ipo_events`；CB 用途與新增得標價格欄位尚未核准。這是用途邊界，不是證交所沒有這些 CB 資料。

## 1. 參考站公開畫面

已再次閱讀 [可轉債資料總覽](https://cyclesinvest.com/convertible_bond_search.php) 及 [CB 發行表](https://cyclesinvest.com/cbipo.php) 的公開頁面。這不是會員 API 或資料庫分析。

- 總覽可組合 CB 價格、轉換價、轉換價值、股價、剩餘比率、擔保、距到期與日期條件；本次落地對應數值／日期篩選及綜合比較檢視。距到期改用「天」以明確按資料日計算，不推測其年化天數口徑。
- 發行表合併公告／送件／生效／競拍／定價／掛牌等節點，也包含信用評等、CBAS 等非本專案允許來源的內容；不會整張照抄。
- 9/8 查看的發行表亦存在空格；例如部分尚未送件／生效／詢圈的案件沒有日期。另有未來生效日，例如 23161 的 9/21、32896 的 9/9，不能僅因有日期便認定已生效。
- 「發行轉換溢價比率」約 104% 是發行條件口徑；本站「市場轉換溢價率」是 CB 市價與轉換價值之比減一，不能混成同一欄。

### 正式接入驗收條件

1. 明確核准 CB 用途；保留原 IPO parser 與政策，另建五至六碼 CB 契約，不削弱股票限制。
2. 僅接受「有擔保轉換公司債／無擔保轉換公司債」，排除四碼股票 IPO、交換債與其他未確認類型。與 11406 以完整 CB 代碼對應；同公司不同期不能只用公司碼合併。
3. 全部 26 格 schema、年度、實際日曆日期、資料筆數、重複案鍵、數值與取消狀態需有嚴格驗證。取消及重複樣本目前尚未取得，不聲稱已全數驗證。
4. 投標起／迄、開標、撥券分開保存；不得把開標日直接當成轉換價訂定日或申報生效日。
5. 最低投標、最低得標、最高得標、加權平均、實際承銷分欄；沒有正式结果或取消時不得發布看似有效價格。CB 發行額不以競拍張數推估。
6. 與條款掛牌日發生衝突時保留雙方證據，禁止靜默覆寫；沒有競拍資料不代表沒有 CB（可能採詢圈）。
7. 更新失敗不得切換第三方；最後一份有效資料保留自己的原始日期。授權／商業利用須依精確 resource 覆核，不能把 11406 的 OGL 自動套到另一個來源。

## 3. 送件／生效：證期局附件仍有障礙

[證期局申報案件頁](https://www.sfb.gov.tw/ch/home.jsp?id=1016&parentpath=0,6,52) 在本次檢查明列「115年度申報案件」更新日 **115.9.8**，但頁面當下的 XLSX／ODS 連結無法取得有效試算表：

- 頁面實際 XLSX：`https://www.fsc.gov.tw/userfiles/file/1150908%E7%94%B3%E5%A0%B1%E6%A1%88%E4%BB%B6%E5%BD%99%E7%B8%BD%E8%A1%A8.xlsx`
- 頁面實際 ODS：`https://www.fsc.gov.tw/userfiles/file/1150908%E7%94%B3%E5%A0%B1%E6%A1%88%E4%BB%B6%E5%BD%99%E7%B8%BD%E8%A1%A8.ods`
- XLSX 網頁讀取導至金管會首頁；ODS 下載最終 HTTP 200 但內容為 HTML 首頁，而不是 ODS ZIP。
- 拒收內容 144,239 bytes，SHA-256：`3b51e043044a1851fb7598ae356d76a5d14fba3c80fcad9214ee7efb28e8cd11`。本機快取更名為 `.cache/sfb-1150908-rejected-html.html` 避免後續誤當試算表；沒有刪除，也沒有匯入。
- 不能僅看 HTTP 200 或副檔名，必須驗 Content-Type、檔案簽章、ZIP 結構、工作表、標頭、資料日與案件狀態。
- [SFB 開放宣告](https://www.sfb.gov.tw/ch/main.jsp?dataserno=201605130008&mtitle=%E6%9C%AC%E6%9C%83%E7%B6%B2%E7%AB%99%E8%B3%87%E6%96%99%E9%96%8B%E6%94%BE%E5%AE%A3%E5%91%8A&websitelink=artsublink.jsp)有開放利用規則；附件內容與個別例外仍需核對。registry 維持候選，尚無正式 adapter。

因此，今天尚未拿到可驗證的 9/8 申報明細，沒有以舊附件或參考站填補。送件、生效、撤回資料仍未完整接通。取得有效附件後，必須分別驗證實際／預計生效及同公司多案，撤回、撤銷、退件排除於進行中表，但在後台保存事件證據。
