# V5.2 資料正確性、搜尋重建與技術分析暫停計畫

建立日期：2026-08-29  
執行分支：`codex/market-event-radar-ux2`

本計畫以《台灣盤後市場資訊台 V5.2》為唯一需求來源；不新增未經驗證的研究指標、私有資料或會員功能。

## 執行順序

1. **基準與契約**：記錄 active generation、資料量、跨市場抽樣與現有全量測試結果；將基準只用於回歸，不做前端常數。
2. **正規主檔**：在 staging 階段由已驗證公開資料建立唯一公司主檔、可轉債主檔與 `search-index.json`。公司以四碼代號為鍵；可轉債僅可用 `issuerCode` 關聯，不能以名稱猜測。
3. **搜尋重建**：頁首保留唯一搜尋元件，移除首頁第二搜尋框。搜尋先讀 `search-index.json`，明確區分未建立、載入失敗、網路失敗與查無結果；支援四碼股票、五／六碼 CB、公司與債券名稱、別名、全形字元、鍵盤與 Ctrl/Cmd+K。
4. **公司頁統一關聯**：公司頁先取得公司主檔，再以相同代碼讀取興櫃、IPO、月營收、CB、事件。顯示分頁為概覽、營收、IPO／事件、可轉債、公開事件；沒有 IPO 時顯示「目前沒有 IPO 進行資料」。
5. **暫停未驗證技術分析**：移除公開公司頁的技術分析分頁、K 線與 MA／MACD／RSI／KD／BOLL 控制項；保留資料管線，不把任何推估值替代為市場資料。
6. **資料狀態與日期**：金融欄位的遺漏為 `—`、官方尚未公布為「待公布」、無成交為「今日無成交」、取得失敗為「資料暫時無法取得」。所有頁面使用真實資料日期；快照失敗時沿用上一份已驗證 generation。
7. **回歸與部署**：執行單元／staging／全量測試、lint、typecheck、build、靜態安全掃描、公開網址煙霧驗證後，才推送與發布。

## 測試策略

- 每個行為先寫失敗測試，再寫最小實作。
- 搜尋驗收：`2303`、`聯電`、`3313`、`斐成`、現有五／六碼 CB、部分名稱、全形空白代碼、無效代碼、索引 404。
- 關聯驗收：公司市場只由公司主檔決定；CB 只以標的代碼關聯；IPO 使用正式公司代號；20 支股票、20 檔 CB、10 個缺值與 5 個載入失敗情境回歸。
- 前台安全驗收：輸出不得含 `sourceId`、`missingReasons`、快照識別碼、個資、內部錯誤詳情或未驗證技術分析。

## 部署前阻擋條件

- 搜尋把索引錯誤誤當成「查無結果」。
- 任一市場／公司／CB 連結只靠名稱模糊關聯。
- 缺值、抓取失敗或沒有成交被顯示為 `0`。
- 公開頁仍可看到技術分析、K 線或技術指標。
- Build、全量測試、lint、typecheck 或公開煙霧測試失敗。
