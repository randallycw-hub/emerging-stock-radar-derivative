## 本輪修正

1. 全站共用藏青／青綠工作台樣式，縮短大標題與留白，保留完整明細、深淺色與手機版。
2. CB 篩選 URL 保留查詢、快速條件、排序與視圖；修正空值當零、零值排序、過期停止轉換條件。
3. 無成交與缺資料分開：歷史有效價格保留真實成交日，不與新股價混算同日溢價。
4. 按當日已生效的轉換價格計算。84732 於 9/4 使用 34.1，而非 9/14 才生效的 30.3；股價 45.7、CB 131、轉換價值 134.02、同日溢價 -2.25%。
5. 發行頁保留受託人，與個券條款一致；公司頁可重用已取得、具日期的標的股票收盤，不呈現不適用的興櫃均價欄位。
6. 首頁異動標示真實比較日期 8/28 → 9/4；靜態與互動首頁均以資料日起 7 日的同一事件窗口呈現。
7. IPO 保留目的市場，不被公司目前市場覆蓋；未來競拍日期不稱「已開標」；撤件等終止案件不列入進行中計數。
8. 發布建置先產生官方驗證事件，再清除內部來源識別。修正來源有 6,688 筆 IPO 歷史事件、發布檔卻剩 0 筆的順序錯誤；CB／IPO 事件保留數量加入建置回歸測試。
9. 市場事件賣回／到期／掛牌保留各自名稱，不都顯示為一般公開事件。
10. 週數據顯示已收錄日數；歷史不足、跨期過久或缺去年年底基準時不計算假期間績效／YTD。
11. 每日更新依官方已發布交易日啟動，保留同日行情及來源驗證閘門；既有 22:30 排程改為完整資料重試。
12. 本機預覽使用本機同一代資料，正式網站仍使用既有 GitHub 公開資料鏡像，不混用新舊代。
