## 發布階段安全邊界

- 公開 JSON 僅保留投資人可閱讀的事實與 `verified` 標記；來源代號、原始記錄識別碼、資料集／資源代號、缺漏原因、風險評估與診斷會在發布時移除。
- 內部 Excel 匯入、差異檢查、來源健康狀態與帳號／憑證不在靜態網站輸出中。
- 前台只顯示已成功發布的資料日期，沒有資料時以中性空狀態呈現，不宣稱不存在或自行補值。

## 來源核准阻塞

以下群組尚無目前已核准、可穩定擷取的官方結構化來源。它們仍不會以第三方資料、猜測值或零值替代：

| 資料群組 | 安全行為 | 狀態 |
| --- | --- | --- |
| 興櫃新增／終止／異動名錄、完整公司注意／處置／暫停狀態 | 只呈現目前已驗證欄位，不建立假異動 | 來源核准阻塞 |
| 興櫃買價／賣價與完整推薦券商資訊 | 以 `—` 保留欄位語意，不混入未核准即時資料 | 來源核准阻塞 |
| TDCC 股權分散 | 不建立股東級距或週變化推估 | 來源核准阻塞 |
| 標的股票融資、融券、借券 | 不以舊值冒充當日籌碼資料 | 來源核准阻塞 |
| 季報 EPS、毛利率、營業利益率、現金、負債比與營業現金流 | 目前只顯示可核對月營收，其餘不填補 | 來源核准阻塞 |
