# 市場公開研究平台 V2 發布前清單

本清單只涵蓋公開網站。私人 Excel 匯入、來源識別碼、缺漏原因、抓取紀錄及個資均不在公開輸出範圍。

| 項目 | 實作與驗證 | 狀態 |
| --- | --- | --- |
| 公開邊界與舊連結 | 禁止第三方主資料與投資指令；`bonds.html?bond=` 保持可用 | 完成 |
| 來源與時間 | 已核對欄位保留公開資料日期；缺值呈現 `—` | 完成 |
| 發布品質閘門 | 交易日、重複身分、日期回退、資料衝突在發布前拒絕 | 完成 |
| 更新模式 | FAST、OFFICIAL、EVENT、RECONCILE、WEEKLY 已明確區分 | 完成 |
| 興櫃 | 盤後均價、無成交與公司詳情採公開資料投影 | 完成 |
| IPO | 雷達、時程與正式事件共用生命週期投影；終止／撤件不列入預設進度 | 完成 |
| 可轉債生命週期 | 交易中、今日無成交、暫停、贖回、到期等狀態採明確優先序 | 完成 |
| 可轉債轉換價 | 依生效日選用版本，不用目前值回填歷史 | 完成 |
| 可轉債公開頁 | 市場總表、條件篩選、發行案件、公開事件與詳情頁 | 完成 |
| 首頁與資料中心 | 跨市場摘要、公開事件、五項主導覽與來源／方法入口 | 完成 |
| 搜尋與方法 | 僅索引公開代碼、名稱、站內連結；說明無成交與 Asia/Taipei 規則 | 完成 |
| 個資與安全 | 不公開帳密、會員資料、Excel、來源 ID、缺漏原因或內部診斷 | 完成 |
| 生產資料限制 | 僅使用逐一核可的 TPEx、TWSE、MOPS、TDCC 公開來源 | 持續由來源契約與發布閘門執行 |
| 發布前驗證 | `npm test`、`npm run typecheck`、`npm run lint`、`npm run build`、`git diff --check` | 待最終一次執行 |

## 發布前人工檢查

- 首頁、興櫃、公司詳情、IPO 雷達、IPO 時程、可轉債總表／篩選／發行／事件／詳情、資料中心與方法頁均可開啟。
- 桌機與手機寬度下，表格、搜尋、導覽與明細沒有水平破版。
- 搜尋及公開頁面不含來源 ID、私有檔案名稱、憑證、帳號、缺漏原因與投資指令。
- 僅在使用者明確同意後，才可合併並透過既有 Sites 流程發布。
