### 申報案件接入前必須解決

1. 附件內的實際生效日期與「預計」日期、未結案狀態分開；未来日期不當成已完成。
2. Excel／ODS 重複欄列與合併格須正確展開，不能錯位。
3. 公司代號不足以唯一辨識某一期 CB，同公司多案必須保留獨立案件鍵；不能只用公司代號與大致日期合併。
4. 撤件、自撤、撤銷與退件退出進行中名單，但保留內部追蹤證據。
5. TDCC 保管餘額、發行人流通餘額、標的股票股權分散是不同口徑，禁止互補同一欄。

## 本次落地與防錯

- 可轉債資料總覽縮小標題與留白，沿用五種資料檢視；成交量檢視移除樣本期間。
- 個券採六项有日期核心數字、交易概況／條款與估值／權利事件／標的公司分頁及雙欄對齊明細。
- 新發行頁為 18 欄表格：身分、發行條款、五個公告流程日期、初始／現行轉換價、掛牌／發行／到期、案件狀態與官方來源。固定表頭和 CB 識別欄、搜尋、範圍切換、清除條件。
- 不再默默裁成 30 件；仍限定有官方節點的案件與掛牌日前後 90 天。掛牌當天歸最近掛牌。
- 初始與現行轉換價透過 CB 代碼及公司代號精確對應；重複鍵拒絕補值、價格缺值不回退成初始價格、現行轉換價另列生效日。
- 11406 新欄位同時驗證債券鍵、公司與條款資料日期。可排除原 importer 已定義的無交易代碼私募未掛牌列，但非私募的錯誤代碼、重複代碼與日期不符仍令建置失敗。
- 募集方式的數字代碼尚未取得獨立官方代碼表，保留空值，不猜測「公募／私募」顯示。
- 保留 HTML 逸出、官方來源 URL 白名單、Tab 鍵／方向鍵與本站返回連結白名單。沒有新增會員、個資或密鑰。
