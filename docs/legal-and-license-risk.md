# 法律、授權與資料風險

本文件是工程風險控管，不是法律意見。所有商業使用結論須由人工或法律顧問確認。

## 已取得的官方證據

- 政府資料開放授權條款第 1 版：https://data.gov.tw/license
- 櫃買中心網站使用條款：https://www.tpex.org.tw/zh-tw/gtsm_disclaimer.html?l=zh-tw
- 櫃買中心 OpenAPI Swagger：https://www.tpex.org.tw/openapi/swagger.json
- 證交所 OpenAPI Swagger：https://openapi.twse.com.tw/v1/swagger.json

政府資料開放授權條款第 1 版第 2 條允許不限目的、時間及地域、免授權金利用，包含重製、散布、公開傳輸、編輯、改作及開發產品或服務；第 3 條要求依附件顯名。條款不授與專利權及商標權。每個來源仍須個別核對資料集、端點、提供機關、條款版本與欄位白名單，不能只因端點可讀就批准。

## 2026-07-20 個別資料集判定

完成上述個別核對後，資料集 11406、11747、94025、28568、11394 及其 Registry 指定 TPEx 端點，在欄位白名單內列為 `APPROVED`。判定依據是各資料集頁均明示 OGL 1.0，官方 Swagger 存在相符端點，實際欄位可對映，且顯名與 Logo 限制已記錄。

顯名格式採 OGL 附件要求：

1. `金融監督管理委員會證券期貨局 2026 [資料集正式名稱]`。
2. `此開放資料依政府資料開放授權條款進行公眾釋出，使用者於遵守條款前提下得利用之。`
3. 連結 `https://data.gov.tw/license` 及個別資料集頁。

另顯示「資料經興債觀測網整理」及資料日期／擷取時間，不使用任何機關 Logo，也不暗示官方背書。

櫃買中心一般網站條款限制未經同意的自動抓取；因此只能評估正式 OpenAPI／data.gov.tw 資料，不得抓一般網頁、下載按鈕或內部接口。

## 主要風險

| 風險 | 控制 |
|---|---|
| 公開可讀被誤認為可商用 | registry 預設 `PENDING`，只有人工批准能轉 `APPROVED` |
| OpenAPI 與資料集條款不一致 | 同時保存端點、資料集頁、條款版本與查核日期 |
| 欄位含第三方權利或商標 | 僅使用批准欄位；不展示來源 Logo；商標權另行確認 |
| 快取／歷史保存權不明 | 不啟用正式持久化；批准紀錄須明列快取與保存 |
| 一般網站反爬限制 | 禁止 HTML scraping、瀏覽器自動化下載與內部接口 |
| 來源 schema 靜默變更 | schema 驗證、隔離錯誤紀錄、`PARTIAL` 狀態與人工警報 |
| TWSE 欄位疑似錯位 | `twse-listing-applications` 維持 `PENDING`，人工核定前不介接 |
| 未授權 fallback | 程式與測試禁止 Yahoo、CBAS、券商及代理轉抓 |
| 日終資料被誤述為即時／收盤 | UI 固定標示日終；興櫃平均價只能叫日均價 |
| 財務決策誤導 | 顯示資料時效、來源及免責聲明；不給建議、信號或保證 |

## 批准、撤回與下架

- 批准需記錄審查日期、精確來源、欄位、用途、條款及歸屬；本輪審查紀錄於 Source Registry，正式 adapter 仍須獨立測試與 commit。
- 條款、端點或欄位變更時自動降為 `PENDING`，停止新資料發布。
- 來源撤回授權時停止同步；是否刪除既有快照依保存權人工決定。
- 來源失敗不得切換到未批准來源。

## 顯示要求

每個正式資料頁顯示提供單位、資料集名稱、原始網址、資料發布時間、本站擷取／更新時間、授權名稱及必要歸屬。頁尾與關於本站顯示：資料供資訊整理，不構成買賣建議；使用者應回到官方來源核對。
