## 3. 股權分散內頁

由籌碼分頁開啟 [3149 股權分散](https://cyclesinvest.com/tdcc_holders.php?stock=3149)，並實際展開 2026-09-04 那週的十五級距。查到總人數、總股數、平均持有、不同大戶門檻與逐級距人数／比例；歷史行另有股價與週變化。

直接官方對應為 [TDCC 集保戶股權分散表](https://www.tdcc.com.tw/portal/zh/smWeb/qryStock)。官方說明以每週最後營業日餘額、ID 歸戶與持股分級編製；[政府資料集 11452](https://data.gov.tw/dataset/11452?page=1&qt-topic_search=1)列出的欄位是日期、證券代號、分級、人數、股數及比例，且有開放授權標示。該政府 metadata 的頻率寫「每月」，與查詢頁每週編製說明不同，正式接入要以實際檔案日期及提供機關說明覆核，不能只信 metadata。

不可拿 [CB 月分析表 11462](https://data.gov.tw/dataset/11462) 當成 TDCC 股票級距來源；也不能把每月 CB 資料硬補成每週觀測。本站要累積真正不同日期的快照，才有週／月比較，不能重複同一筆造成假歷史。

## 5. 發現的跨頁落差與不能照搬之處

以下是查核時頁面顯示差異，**不是已用官方資料判定哪個數字正確**：

1. 正達四總覽展開列的發行日顯示 2026/12/01；個券頁顯示 2026/08/31。既有官方條款對照中，12/01 是轉換開始日，顯示名稱不能混用。
2. 正達的可轉債頁與公司頁都標示 26M07、營收 2.14 億，但月增分別為 -36.5% 與 5.63%，年增 72.6% 與 24.1%；同標籤不是同數據。應增加相同公司、相同期間、相同口徑的跨頁 QA。
3. 正達個券基本資料顯示股東 42,369 人，另一個籌碼／公司頁為 67,866 人；缺基準日便無法比較。不得全站套一個「最新日期」。
4. 聯電二完整券碼連結會先展開聯電一。本站現有 `bonds-page.js` 按完整 `cbCode` 精確選券；保留此方式，不退回公司第一檔。
5. 新發行 CB 沒有上週資料時，參考站仍有前期 0 與週增減 0%。缺歷史、除數零與真的零異動是三件事，本站不得合併。
6. 稀釋百分比的分母可能採轉換前或轉換後股數，且股本有期間差异；未驗證公式前不照搬顯示值。任何估算要與官方條款值分開。
7. 發行時約 104% 的定價溢價比率，與 CB 市場溢價率不是同一公式。初始轉換價也不是現行轉換價。
8. [TCRI 是 TEJ 的信用風險指標](https://www.tejwin.com/news/tcri-%E4%BB%8B%E7%B4%B9/)，不可自行重算後冠同名，也不能因他站顯示就認定有轉授權。CBAS 同樣不屬本專案允許抓取範圍。

## 6. 調整順序與實際完成界線

1. 本批先完成「綜合比較 + 組合篩選 + 安全返回」：13 欄共用既有數據、七組數值區間、兩組日期區間、擔保、排序與 URL 還原；保留預設行情及原有五種檢視。

3. 再補公司層次的財務／法人／股權資料，沿用同一份 canonical 公司資料、各自期間，避免多頁各抓一份失去一致性。
4. 最後處理可轉股數、稀釋、前後期餘額與輸出圖卡；先取得足夠歷史、公式依據與單位，再讓前台出現完整區塊。
