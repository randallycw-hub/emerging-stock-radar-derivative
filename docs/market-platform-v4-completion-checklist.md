## 研究工作流程

- [x] 首頁提供每日摘要、興櫃排行、近期 IPO、可轉債快速條件與公開事件流。
- [x] 首頁與頁首可搜尋公司、股票代碼與可轉債；支援 Ctrl/Cmd+K。
- [x] 搜尋結果先呈現去重的公司總覽，再依興櫃、IPO、可轉債分組。
- [x] 興櫃頁整合市場摘要、漲跌幅、成交量、月營收與全部公司視圖。
- [x] IPO 雷達、完整時程、競拍／申購／掛牌維持同一研究群組，且只顯示可核對公開事件。
- [x] 可轉債以搜尋與客觀快速條件為先，保留進階篩選與轉換價值／溢價率的公開定義。
- [x] 公司頁整合總覽、IPO、月營收、可轉債與事件，支援 URL 分頁與鍵盤操作。
- [x] 興櫃、IPO 與可轉債清單都連至同一個公司整合頁。
