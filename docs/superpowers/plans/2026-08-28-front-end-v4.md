# Front-end V4 Productization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform the public market site from an engineering-oriented dashboard into a daily-use research tool for emerging stocks, IPOs and convertible bonds without changing any published financial definitions or source pipeline.

**Architecture:** Keep the existing static showcase and generation artifacts as the only public data source. Add a small presentation-only V4 layer in `static-showcase/assets/` for shared navigation, search grouping, date context and cross-market company links; pages retain their existing loaders and derive all new summaries from those published artifacts. Move Data Center V3 to a non-navigation system-status route while preserving the legacy path.

**Tech Stack:** Static HTML, browser ES modules, CSS custom properties, existing Node test runner, Vinext and the existing static staging script.

**Spec:** `C:\Users\USER\Desktop\台灣盤後市場資訊台_V4_前台產品化_Codex完整改版執行規格.pdf`

## Global Constraints

- Do not alter official sources, raw snapshots, pipeline contracts, financial calculations, IPO lifecycle definitions or deployed framework.
- Public UI never invents a value: unavailable remains `—`; verified zero remains `0`.
- Do not add recommendations, buy/sell language, valuations labelled as cheap, or new investment scoring.
- Use V4 Noto Sans TC-first typography, neutral surfaces, Taiwan red-up/green-down semantics, 8/12px radii, compact 14px data density and WCAG-visible focus states.
- Keep Data Center operational diagnostics off the primary navigation; retain `/data-center.html` as a working legacy route and expose a noindex `/system-status.html` route.
- All new renderers escape externally sourced text and link only to project-relative pages or validated HTTPS official URLs.
