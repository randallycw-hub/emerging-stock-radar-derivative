# 2026-07-28 儀表板與資料導覽改版規格

## 目標

在不依賴外部同步成功的前提下，改善首頁與手機版閱讀順序、統一 Cloud Dancer × Transformative Teal 視覺系統、提高資料狀態透明度，並讓公司、債券、IPO 三個資料入口更容易理解與使用。

## 使用者流程

使用者進入首頁後，依序看到：網站定位與目前資料狀態、今日摘要、三個資料入口、來源與更新說明。桌面版保留側邊導覽；手機版改用可展開的頂端導覽，所有主要入口都能在兩次點擊內到達。

## 視覺系統

- Cloud Dancer 米白作為畫布與主要背景。
- Transformative Teal 作為主要操作、連結、狀態成功色。
- 深墨藍作為文字與導覽底色。
- 暖金只用於「待更新／需留意」狀態，不用於裝飾性漸層。
- 維持清楚邊界、低陰影、細線分隔與高資訊密度，避免通用 AI 紫藍漸層風格。

## 元件與頁面

1. 首頁：重排首屏順序，摘要卡片在小螢幕改為單欄，表格可水平捲動且不造成頁面橫向溢出。
2. 狀態區塊：顯示資料狀態、最後更新時間、來源名稱、官方來源連結；同步不可用時顯示可理解的說明，不使用假資料補位。
3. 導覽：公司、債券、IPO 各自擁有明確標題、用途短句與入口卡片；桌面／手機導覽共用同一組路由標籤。
4. 內容頁：保留既有資料契約與禁止市場報價／推薦邊界，只改善標題、空狀態、篩選提示與返回導覽。

## 互動與無障礙

- 所有卡片入口使用可聚焦的連結或按鈕，具備可見 focus 狀態。
- 手機導覽可用鍵盤與觸控開關，開啟時不遮蔽頁面標題。
- 狀態色不單獨承擔語意，搭配文字與圖示。
- 文字維持繁體中文，修正目前 metadata 的編碼錯亂。

## 驗證

- 執行既有測試與 production build。
- 檢查首頁、公司、債券、IPO 路由均能編譯，且沒有新增外部資料請求或禁止的市場資料欄位。
- 檢查窄螢幕樣式規則，確保表格局部捲動、頁面本身不橫向溢出。
