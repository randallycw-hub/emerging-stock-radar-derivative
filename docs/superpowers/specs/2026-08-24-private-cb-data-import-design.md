# 私有可轉債資料匯入與發布閘門設計

## 目的與範圍

建立只在使用者電腦執行的資料管理工具，用於匯入 CBAS 報價表與 CB 發行案件更新檔，檢查與前一快照的差異，並產生可發布的公開資料快照。公開市場網站不提供此工具入口、不傳送原始 Excel，也不讓訪客上傳或下載受限資料。

本設計處理可轉債報價、到期／強制贖回、停止轉換及發行案件事件；不建立會員、投資部位、交易紀錄或個人資料功能。

## 資料權限與來源分級

| 分級 | 範例 | 儲存與使用規則 |
| --- | --- | --- |
| 官方公開 | TPEx／TWSE／公開觀測站公告、盤後與條款 | 可交叉驗證後納入公開快照；每筆保留來源網址與資料截至日。 |
| 使用者提供／可能受限 | CBAS 報價、TCRI、券商整理的發行案件表 | 原始檔僅存於本機私有工作區；預設僅後台可見。未確認有再散布權前，不將原始數值發到公開網站。 |
| 第三方會員或私有來源 | 同業會員頁、登入後的分析內容 | 僅研究資訊架構與功能；不得爬取、繞過登入、複製或推測其私有資料。 |

公開資料快照的每個欄位均須標示 `official`、`licensed-public` 或 `not-applicable`。`licensed-private` 欄位只能留在本機後台。

## 架構與資料流

1. 本機管理工具僅綁定 `127.0.0.1`，不綁定區網位址，且不納入公開網站導覽或部署產物。
2. 使用者選取 `.xlsx` 檔案；匯入器拒絕其他副檔名、巨集檔、異常壓縮大小、未知工作表及不符合欄位結構的檔案。
3. 匯入器從檔名及工作表內日期擷取資料截至日，計算 SHA-256 雜湊，建立不可覆寫的原始快照紀錄。
4. 依債券代碼轉為標準欄位：報價、轉換價值、CB 市價、溢折價、餘額、發行張數、波動度、到期／強贖、停止轉換及發行案件時程。
5. 差異引擎以「資料集類型 + 債券代碼 + 資料截至日」比較上次已核准快照，分為新增、更新、移除、重複、格式錯誤與需人工核對。
6. 核對器比對官方代碼、公告日期、掛牌／到期日期與可公開條款；無法核對者只進例外佇列，不會寫入公開快照。
7. 管理者檢視差異摘要並明確核准後，發布器才輸出不含私有欄位的公開快照，供現有網站建置使用。

## 不顯示空白或「待確認」的規則

- 已核准欄位採最後有效快照並顯示資料截至日；收到較新檔前不清空資料。
- 遇到新值缺漏、代碼不符或驗證失敗時，公開頁維持前一筆有效值，後台建立例外項目與原因。
- 邏輯上不適用的欄位標示「不適用」；其餘未授權或未驗證欄位不在公開卡片／篩選器中出現，避免以「目前無核准公開資料」代替數據。
- 公開頁只有在來源權限及完整度均通過時才可顯示數值；不得以預估、補零或其他債券資料填補空缺。

## 安全與個資保護

- 原始上傳檔、雜湊、差異報告與私有快照均排除 Git、靜態網站產物與前端 API 回應。
- 後台不蒐集帳號密碼、身分證號、投資部位或下單資料；不使用第三方追蹤碼。
- 匯入前驗證 MIME／副檔名、檔案大小、壓縮展開比例及欄位白名單；所有顯示文字與代碼均轉義。
- 公開連結限定官方 HTTPS 來源白名單，開新分頁一律使用 `noopener noreferrer`。
- 發布動作需在本機明確確認，不自動上傳、推送或部署。

## 驗收與測試

- 使用 2026-08-14、2026-08-21 發行案件檔驗證新增、更新與已移除列的差異判定。
- 使用 2026-08-24 CBAS 報價表驗證報價、即將到期及停止轉換三個工作表映射。
- 驗證無效日期、重複債券代碼、缺必要欄位、未知工作表及巨集檔會被拒絕且不改變先前已核准快照。
- 驗證公開輸出不含 TCRI、CBAS 或其他 `licensed-private` 欄位；獲明確公開授權後才允許該欄位進入輸出。
- 驗證所有公開資料欄位具有來源、資料截至日與資料完整度，且例外不會清空先前有效資料。

## 非目標

- 不模擬或取得其他會員網站的私有資料。
- 不提供投資建議、買賣訊號或自動交易。
- 不建立公開的檔案上傳端點或以隱藏網址取代存取控制。
