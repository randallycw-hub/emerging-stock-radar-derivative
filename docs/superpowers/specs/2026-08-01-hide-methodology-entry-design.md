# 隱藏「資料方法」公開入口設計

日期：2026-08-01

## 目標

公開網站不再特別列出「資料方法」，讓主要導覽專注於首頁、可轉債、興櫃市場與 IPO 行程。資料方法頁仍保留，供持有直接網址的人查核資料來源與計算方式。

## 範圍

- 從正式靜態網站的首頁卡片、全站導覽與頁尾移除「資料方法」連結。
- 從仍可直接存取的舊版公開頁面導覽移除「資料方法」連結，避免其他入口再次顯示。
- 從 sitemap 移除 `/methodology`，避免把它當成主要公開頁面列出。
- 保留 `static-showcase/methodology.html` 與 `app/methodology/page.tsx`，直接網址仍可開啟。
- 保留資料來源、公式、核准紀錄與程式內驗證邏輯。
- 不修改正式資料快照、計算結果、排序、篩選、配色或其他頁面內容。

## 公開資訊架構

主要導覽固定為四個入口：

1. 首頁
2. 可轉債
3. 興櫃市場
4. IPO 行程

首頁只呈現三個市場功能入口：可轉債、興櫃市場與 IPO 行程。頁尾保留網站名稱與投資風險聲明，不再提供資料方法連結。

## 相容性

- 既有 `/market-site/methodology.html` 與 `/methodology` 不重新導向、不刪除，也不回傳 404。
- 直接進入資料方法頁時，內容與公式維持原樣，但全站導覽不再列出該頁。
- 深淺色、鍵盤導覽、行動版選單與資料載入流程不受影響。

## 驗證

- 測試四個主要公開頁面的導覽不含 `methodology`。
- 測試首頁不再有資料方法卡片。
- 測試頁尾不再有資料方法連結。
- 測試 sitemap 不再列出 `/methodology`。
- 測試兩個資料方法直接網址的來源檔仍存在，內容與公式檢查仍通過。
- 執行完整遞迴測試、lint、typecheck 與正式建置後才發布。
