# 興債觀測網：Yahoo 與股價功能移除設計

## 目標

在不新增興櫃、可轉債、會員、付款、廣告或部署功能的前提下，將現有網站清理為「興債觀測網」的安全開發基線。正式程式不得呼叫或呈現 Yahoo、券商網站、未授權行情 API、即時股價或延遲股價。

正式品牌名稱固定為「興債觀測網」，副標題固定為「興櫃公司、可轉債與上市櫃進度資訊」。

## 採用方案

保留現有非股價的官方 IPO／上市櫃申請進度、公司基本資料與可重用的搜尋、篩選、導覽、表格和響應式元件；移除 Yahoo 資料層、所有行情資料流、價格欄位、價格排序、技術線圖、第三方新聞與只為股價存在的畫面。

未採用的替代方案：

- 全站改為純靜態施工頁：最安全，但會不必要地捨棄已存在的非股價官方進度資料與可重用介面。
- 刪除全部資料頁：範圍超出本次 Yahoo 與行情清理，且不利於後續正式功能開發。

## 架構邊界

### 保留

- Next.js／Vinext／Vite／Cloudflare Worker 的既有專案結構。
- `.openai/hosting.json` 的既有 project ID；本次不使用它部署。
- 非股價的官方公司基本資料與 IPO／上市櫃進度處理。
- 只讀 API、CORS、搜尋、篩選、導覽、響應式版面及法律／方法說明頁。
- 承銷公告中的「暫定承銷價」與「實際承銷價」僅在它們屬於官方事件進度資料時保留；不得將其當成市場行情、報價或投資建議。

### 移除

- `lib/yahoo.ts` 與 `app/api/yahoo/route.ts`。
- 所有 Yahoo 網域、Yahoo 名稱、Yahoo 型別、Yahoo 快取、重試、fallback 與代理請求。
- Yahoo RSS 新聞、Yahoo 技術線圖及其連結。
- 興櫃即時／延遲成交價、買價、賣價、成交量、成交額、漲跌、週漲跌與相關排行。
- TPEx 興櫃行情端點及行情快照；永久規則禁止即時及延遲股價，因此即使來源為官方亦不得在正式模式使用。
- 只支援行情的 API、型別、工具函式、畫面、CSS 與測試。

## 使用者介面

- 主品牌、metadata、Open Graph、首頁、頁尾、關於本站、README 與測試統一使用新品牌。
- 原行情主區改為清楚的空狀態：「官方資料來源建置中，目前不提供即時或延遲行情。」
- 不顯示看似真實的假資料。若未來加入 fixture 或 mock，正式模式不得載入；本次不新增 fixture 或 mock。
- 非股價進度頁可繼續顯示官方公告型資料，並揭露來源與更新時間。

## 測試策略

1. 先新增／改寫防回歸測試，要求正式程式不含 Yahoo、券商行情、即時／延遲股價入口，並要求品牌及副標題完全一致。
2. 先執行測試確認它因現有 Yahoo 與舊品牌而失敗。
3. 移除資料層與畫面後重新執行測試。
4. 依序執行 `npm ci`、`npm test`、`npm run lint`、`npm run typecheck`（若有 script）與 `npm run build`。
5. 最後以全專案搜尋檢查；`docs/yahoo-removal-audit.md` 與本設計文件可保留 Yahoo 文字，其餘正式程式、設定與介面不得殘留。

## Git 與安全

- 清理前基線分支為 `chore/pre-yahoo-removal-baseline`，固定指向清理前 HEAD。
- 不改寫、刪除或覆蓋既有 Git 歷史。
- 最終清理以獨立 commit 提交。
- 不修改工作區根目錄外的檔案，不部署，不更改資料夾名稱、repository 名稱或部署 project ID。
- 所有 CPU 密集工作設為低於正常優先權，最多使用 2 個執行緒。
